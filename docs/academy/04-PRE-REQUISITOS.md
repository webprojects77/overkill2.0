# 04 — Pré-requisitos

Fonte: Documento 04 e Documento 00 §8.

- Pré-requisitos formam uma rede, não uma lista. Cada assunto declara seus pré-requisitos.
- Nível e ordem são calculados a partir da rede. Editar uma ficha não exige renumerar.
- Pré-requisito ausente gera aviso com links. Nunca bloqueia a aula.
- Revisão contextual: se o aluno já domina um pré-requisito, recebe revisão breve. Se tem dificuldade, recebe explicação complementar.
- Domínio é diferente de ter visto a aula, de concluir atividade e de acertar uma questão (§8.4).
