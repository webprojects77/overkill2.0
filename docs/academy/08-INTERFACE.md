# 08 — Interface

Fontes: Documento 00 §3, §4, §21; Documento 12, fase 4.

Site institucional (§4): Início; Nossa proposta; Formação; Como funciona; Colaboradores; páginas legais; FAQ; botão de inscrição; links institucionais.

Identidade (§3.3): preto profundo, azul-marinho, azul elétrico, azul luminoso para destaques, branco suave para texto, tons neutros. Tipografia moderna. Evitar aparência infantil. Transições discretas. Cards com transparência sutil.

Responsividade: computador, notebook, tablet, smartphone. Mobile desde o início.

Acessibilidade (§21): navegação por teclado; contraste; textos legíveis; alternativa textual para imagens; legendas; transcrições; leitor de tela; mensagens de erro compreensíveis.

Fase 4 do Documento 12: separar visualmente as duas formações, melhorar a página inicial, criar navegação entre áreas, melhorar a página de aula, criar páginas de progresso.

Funcionalidade planejada não pode aparecer como disponível.
